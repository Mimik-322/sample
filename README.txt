КОМПЛЕКТ ФАЙЛОВ ДЛЯ НОВОГО ENS-САЙТА
=====================================

Папка ipfs/   — что заливаешь в Pinata одной папкой (получишь CID для ENS contenthash)
   ├── index.html   ← открой и поставь свой SITE_ID вместо "REPLACE_ME"
   └── bg.jpg       ← подготовлю когда пришлёшь картинку как файл (drag-n-drop в чат)

Папка github/ — что коммитишь в репу Mimik-322/ens-sites-data в новую папку <SITE_ID>/
   └── data.json    ← поправь title / ссылки кнопок под нужный сайт

ПОРЯДОК ДЕЙСТВИЙ:
1. Выбираешь новый SITE_ID (любое число, которого ещё нет в репе — например 1234)
2. В репе ens-sites-data создаёшь папку 1234/ и кладёшь туда data.json (отредактированный)
3. В index.html меняешь "REPLACE_ME" на "1234"
4. Пинишь папку ipfs/ на Pinata, получаешь CID
5. В app.ens.domains прописываешь contenthash = ipfs://<CID> для нужного домена
